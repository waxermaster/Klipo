Klipo - take, annotate and copy screenshots.

Usage: klipo [OPTIONS] [FILES...]

If Klipo is already running, the command is sent to the running instance.

Options:
  -h, --help              Show this help message and exit
  -v, --version           Show the version and exit
  --screenshot[=MODE]     Take a screenshot and open it in the editor
                          MODE can be:
                            INTERACTIVE (default) - select an area
                            FULL                  - all monitors
                            WINDOW                - active window (X11; on
                                                    Wayland: pick it in GNOME)
                            SCREEN                - monitor under the pointer
                                                    (X11; on Wayland: all)
  --delay=SECONDS         Wait before taking the screenshot
  --record                Start a video recording
  --stop-recording        Stop the current video recording
  --toggle-recording      Start or stop a video recording
  --new-window            Open a new editor window
  --pin FILES...          Pin images in floating windows

Arguments:
  FILES...                Image files to open

Examples:
  klipo                           Open the editor
  klipo image.png                 Open image.png
  klipo --screenshot              Select an area to capture
  klipo --screenshot=FULL         Capture all monitors
  klipo --screenshot --delay=3    Select an area after 3 seconds
  cat image.png | klipo           Open an image from standard input
